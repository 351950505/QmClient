# Android 纯观战与录像导出

状态：实现完成，运行验收待完成。

## 已确认行为

- 将现有 Android 客户端改为纯观战模式，不新增独立安装包。
- 在线旁观和 Demo 播放都支持玩家选择、前后切换、自由视角、摇杆移动和缩放。
- 画面参考用户提供的横屏样例：保留现有地图、顶部 HUD 和底部旁观 HUD，触控控件保持简洁。
- 在客户端选择 Demo 或视频，再保存到系统选择的位置，或分享给其他应用。

## Android 客户端行为

Android 固定启用纯观战，不提供切回参赛模式的设置。桌面平台继续使用原有操作。连接后收到本地玩家信息即请求加入旁观；服务器尚未确认时最多每三秒重试一次。客户端拒绝加入参赛队伍和连接分身，发送前清除方向、跳跃、开火、钩爪和武器切换输入，保留相机坐标与聊天标记。网络协议和录像格式保持原样。

旧触控布局不再参与 Android 游戏画面中的操作，但保存的布局配置仍保留。新控件由独立 Qm 组件负责：

| 位置 | 操作 |
| --- | --- |
| 左下摇杆 | 按住方向持续移动；松手停止；开始移动时切换到自由视角 |
| 右下第一行 | 上一玩家、玩家选择器、下一玩家 |
| 右下第二行 | 自由视角、缩小、放大 |
| 右上 | 菜单、聊天；Demo 另有暂停／继续 |

摇杆有中心死区，速度随偏移量变化，并按渲染帧时间和缩放换算。打开菜单、聊天、控制台、旁观选择器或 HUD 编辑器时释放触控；失焦、窗口尺寸变化与状态切换也释放触控。中断后需先松手才能重新操作。视频渲染期间不绘制触控控件，避免将它们录进输出画面。

玩家选择器在手指松开后打开，避免打开按钮的同一次触摸误选玩家或关闭面板。

Demo 的录制者视角可以直接切换到玩家，也可以用摇杆或自由视角按钮退出跟随。玩家顺序沿用现有旁观逻辑。在线旁观仍等待服务器确认视角切换；确认前不把世界坐标当作跟随瞄准偏移使用。

## 文件操作入口

- 菜单右上原编辑器图标在 Android 显示为视频图标，打开视频文件列表。
- Demo 浏览器的“Demo 目录”打开可导出列表。
- 设置中的录制卡片同时提供 Demo 目录和视频目录按钮。

列表使用现有媒体目录配置，支持子目录，分别筛选 `.demo` 和 `.mp4`，忽略扩展名大小写。仍在录制的 Demo 不显示。规范化路径后限制在所选媒体根目录内。

“保存到手机”使用 Android `ACTION_CREATE_DOCUMENT`，由用户选择系统目录和文件名。复制在单个后台工作线程执行，成功关闭输出流后才报告完成。取消选择不复制；失败提示重试，并尝试清理由本次操作创建的未完成目标文件。源录像不修改。

“分享文件”先复制到专用缓存，再通过 `FileProvider` 提供临时只读 `content://` URI。Provider 仅暴露 `qm-media/` 分享缓存，外部应用不获得媒体根目录或配置目录的访问权限。应用销毁时取消后台复制，不再弹出旧页面的结果。系统文件选择器期间保存待导出的源路径，供 Activity 重建后的结果处理使用。

Android 原生提示提供英文、简体中文和繁体中文，客户端入口复用现有翻译。
