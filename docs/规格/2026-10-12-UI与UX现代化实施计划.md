# UI 与 UX 现代化实施计划

状态：主流程与基础组件已实现，通过 PR #425 集中交付，待运行验收。构建、测试执行与客户端验收尚未进行。

## 已确认的取舍

- 不提供一键恢复旧版 UI 或旧版 UI 热切换。
- 顶部导航保留左右两组，各有一个选择滑块，统一外观和交互。
- 收藏地图、过图历史、Team 存档与地图收藏夹合并为一个入口。
- 重排设置页之前，先让搜索承担快速查找和当场调整设置的入口。
- 搜索结果直接复用完整可交互卡片，定位原页作为附加操作。

## 设置搜索

玩家可以输入设置名称、配置名、中文口语别名、常用拼音或多个关键词。搜索首先匹配具体设置，再按所属卡片合并展示。

### 匹配与排序

- 设置标签和配置名的精确匹配优先，其次为前缀、普通词项和容错匹配。
- 多个词必须属于同一个设置及其卡片标题上下文，不将同卡不同控件的词拼成一次设置命中。
- 使用字段权重与 BM25 评分，说明文字的权重低于设置标签、配置名和别名。
- 中文按 Unicode 码点处理，支持连续词组分段及中英混输，不要求玩家手工加空格。
- 常用词组补充完整拼音和首字母，未知汉字不猜读音；既有手工拼音关键词继续有效。
- 英文和拼音的容错使用有界 Damerau-Levenshtein 距离，支持相邻字母换位。短词不启用容错，避免结果泛滥。
- 同分保持注册顺序，旧入口别名合并到实际卡片，定位仍读取用户保存的卡片位置。
- 索引按语言构建，查询结果按查询、语言、协议和布局版本缓存。调整配置值不会触发重新排序。

### 页面与交互

- 保留空查询时居中的输入卡片；全空白也按空查询显示。
- 结果默认展开，支持直接修改原卡片中的配置。
- 使用实际配置地址和本地化标签标记命中行；缓存标签和即时标签共用高亮入口。
- 设置页面内按 `Ctrl+F` 聚焦搜索，macOS 使用对应系统修饰键。
- 上下键选择结果，Enter 显露选中卡片中最相关且当前可渲染的设置；没有行几何时保留卡片显露。
- 输入法组合输入、弹层、控制台、按键录制和其他控件的编辑优先于搜索快捷键。
- 搜索页折叠状态独立保存，不改变原分类页偏好。显露折叠结果会将其展开并保持。
- 点击“定位”进入原页后，Esc 先结束文本编辑，再返回保留查询、选择和滚动位置的搜索页。
- 搜索页面编排从 `menus_qmclient.cpp` 移到 `QmUi/SettingsSearchPage.cpp`，卡片业务内容继续由现有目录提供。

### 验收与证据

已补充算法单元测试、搜索会话单元测试、注册表排序集成测试及真实 UI 高亮集成测试。测试直接调用生产接口，未执行。

已进行限定范围静态复核。未编译、未运行测试或 gate、未启动客户端；当前没有延迟、帧率或视觉验收结论。

后续获准运行验证时，检查中文、配置名、拼音、拼写错误、多词换序、语言切换，以及窄窗口、长译文、输入法候选、离屏命中、折叠后显露和定位后返回。性能测量单独记录环境与结果，不由算法名称推导延迟保证。

## 设置分类与兼容

左侧导航按语言、好友、Tee、视觉、资源、声音、控制、游戏界面、功能、搜索、贡献排列。

- 好友包含好友列表、War List 和好友通知。
- Tee 包含外观、玩家身份、角色效果及 Profiles。
- 视觉分为图像与界面体验。窗口、渲染、地图效果归图像；界面配色、字号、导航大小和输入体验归界面体验。
- 控制分为官方绑定、命令工坊、输入可视化。后者复用现有实际绑定键盘、鼠标展示及输入覆盖设置。
- 游戏界面集中 HUD、聊天展示、计分板和禅模式。
- 功能按 QmClient、通用游戏、DDNet、TClient 与配置组织。
- 贡献继续使用栖梦、友链两个子页。

原有页签编号保留，新分类只追加编号。首次进入时通过 `qm_settings_navigation_version` 迁移旧页签含义。全局布局仍使用原来的卡片序列化格式，卡片 ID、列、来源组内排序和用户跨页摆放继续保留。容量扩为 16384 字节，以容纳完整迁移布局。

分类页通过 `QmUi/ModernSettingsPage.cpp` 声明视图和卡片清单，从原有目录构造内容。注册表默认分类继续用于识别卡片实现，现代视图负责展示位置。搜索的定位操作读取同一模型，不另存一套归属。预热、文本计划、工具提示上下文及子页切换缓存同步使用现代视图。

## 顶部导航与工作区

- 左组保留主菜单、互联网、LAN、收藏服务器、地图工作区和全部收藏社区。
- 右组保留截图、回放、地图编辑器、资源编辑器、设置和退出。
- 两组共用槽位尺寸、选择滑块和交互；窄窗口下共同收缩，导航比例独立调整。
- 地图工作区包含收藏地图、过图历史、Team 存档及统计四个子页。
- 资源编辑器成为独立工作区，包含图像和音频两个子页。切换或离开时停止音频预览、结束拖动并关闭借用编辑状态的弹层，保留草稿；重新进入继续编辑。
- 图像编辑器显式关闭仍使用保存、放弃、取消流程。打开控制台后，背景绘制不处理画布点击、延迟点击或重建草稿。

## 基础组件、主题与控制台

- 强调色与选中态统一读取 `qm_ui_accent_color` 和透明度。保留旧选中色配置解析，不再提供独立设置入口。
- 表面透明度、边框、焦点和强调色分别派生，降低表面透明度不再次压暗前景反馈。
- `qm_ui_text_scale` 默认 100，范围 75–150，调整设置卡片文字及对应行高、标题、命中区域和测量缓存。
- `qm_ui_nav_scale` 默认 100，范围 75–150，调整顶部及设置侧栏导航；侧栏按可用高度收敛。
- `qm_ui_scroll_mode` 默认 1（阻尼），0 为原版即时滚动。切回原版时结束剩余惯性，保留 Alt 加速。
- 单行、多行输入框双击全选。普通插入、拖选、外部点击提交继续沿用公共输入实现；输入法消费的 Enter 不报为提交。
- 公共颜色选择器提供预设色与自定义入口，保留颜色空间、Hex 与透明度编辑。
- 界面表面提供圆角、方角选择，默认圆角；游戏实体、地图与碰撞不参与该选项。
- F1、F2 共用字体、背景、语法颜色和设置面板，新增 PowerShell 7 配色。F2 认证输入继续隐藏，认证前不记录命令回显。
- 分类筛选只影响控制台显示，完整日志继续保留；搜索、跟随、设置入口在两种控制台可用。

公共按键识别与清空、Toggle、Checkbox、分段选择器、资源下载/删除确认、下拉锚点和弹层生命周期已有实现，继续复用。卡片动态预览、键鼠绑定展示、Phosphor 图标及可中断的 Morph 沿用现有生产实现；本轮不新增重复状态机。

## 尚待验收

已补充设置迁移与定位集成测试，以及导航布局、编辑器工作区状态、主题透明度、字号几何、滚动模式、控制台配色和真实输入组件测试。仅进行静态审阅，未执行这些测试。

翻译维护 TOML 来源，已通过抽取、生成脚本更新 12 个运行时语言文件；生成成功与游戏内排版验收分别记录。

获得运行验证授权后，按以下路径验收：

1. 从旧配置首次进入，检查目标分类、手动列与排序，以及保存重启后的结果。
2. 从搜索修改设置、定位到新分类，再返回搜索；检查折叠与滚动保留。
3. 在窄窗口和 75/100/150 比例下检查侧栏、长译文、卡片标题、控件命中与顶部社区入口。
4. 滚动中切换模式，检查即时停止、边界、横向列表和 Alt 加速。
5. 图像与音频工作区反复切换、离开、返回，检查草稿、预览停止、弹层与退出确认。
6. 检查 F1/F2 配色、字号、认证输入遮罩、分类筛选、搜索和日志保留。
7. 检查输入法、密码框、双击与拖选、颜色预设、自定义颜色及方角模式。

当前没有构建成功、运行时通过、性能或视觉验收结论。

## 单独提案

界面布局编辑器、额外模糊算法及材质、聊天与 Toast 合并、原版图标切换继续作为单独设计范围，不计入本轮实现。原有高斯、Kawase 和 Dual Kawase 保留。
