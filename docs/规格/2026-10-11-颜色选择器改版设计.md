# 2026-10-11 颜色选择器改版设计

## 背景

基于手绘草图与两轮口头反馈（2026-10-11）对现有取色器做改版设计。现有实现在 `src/game/client/ui_popups.cpp` 的 `CUi::PopupColorPicker`（约 1087 行起），已具备：HSVA / RGBA / HSLA 三模式数值条（`SColorPickerPopupContext::EColorPickerMode`）、SV 二维面板 + 竖向色相条、Hex 输入（6/8 位，`m_HexPrefix`）、A 数值选择器、模式切换按钮，弹窗约 170×219，锚定在调用点弹出。

## 需求确认（用户反馈汇总）

| 需求 | 状态 |
| --- | --- |
| 整体做成二级菜单弹窗页面：标题栏、关闭按钮、分割线，不再固定锚定在调用点 | 已确认 |

## 目标布局（自上而下五区）

1. **标题栏**：图标 + 「颜色选择器」+ 关闭（×），下方分割线。
2. **页签行**：推荐 / HSVA / RGBA / HSLA（对齐现有 `PICKER_MODES`）；页签行右侧「方图 / 色环」形态切换（仅作用于 HSVA 页）。
3. **主取色区**（随页签切换）：
   - 推荐页：24 色预设网格（浅/中/深三行，只读）+「新/旧颜色预览」+「＋ 固定此颜色」；
   - HSVA 页（方图形态）：SV 二维面板（横向 S、纵向 V）+ H 色相条 + A 透明度条；
   - HSVA 页（色环形态）：色环选 H，环内 SV 方图选 S/V（仿 PS，与用户截图一致）；
   - RGBA / HSLA 页：四通道滑条行（R/G/B/A 或 H/S/L/A），每行滑条 + 数值输入框双向。滑条轨道语义按通道绘制：R/G/B 为该通道由暗到亮，H 为色相谱，S 为灰→纯色，L 为黑→色→白（注意 L 与 HSVA 中 V 的语义差异），A 为透明度渐隐。
4. **数值行**：H/S/V/A 或 R/G/B/A 数值输入框 + Hex 输入框（6/8 位，常驻于所有页，对应现有 `DoValueSelectorWithState` 五个 id：H S V A Hex）。
5. **调色板常驻行**：「我的颜色」色块条目（色块 + 名称）+「＋」新增 + 取消/确定按钮。调色板各页常驻。

## 交互与状态设计

- 弹窗以二级菜单页面打开（居中独立窗口），打开时快照「旧颜色」；确定写回调用处输入框，取消还原。
- 方图与色环共享同一组 H/S/V/A 状态，形态切换不丢颜色；RGBA/HSLA/Hex 与 HSV 状态无损换算。
- A 透明度：滑条（HSVA 页）与数值输入框（数值行）双向联动。
- ＋固定 → 当前颜色存入「我的颜色」，改名、删除、跨设置项全局共享、持久化。

## 持久化设计

- 「我的颜色」条目 = 名称 + RGBA（含 alpha），以 `qm_` 前缀配置项存储（分号分隔串或 JSON），跟随现有配置迁移链。
- 内置推荐色只读、随版本内置；无调色板数据时给空列表 + 推荐页兜底。

- `ui_popups.cpp` `PopupColorPicker` 迭代：弹窗扩为约 400×276 逻辑像素的二级弹窗页面，加标题栏/分割线/页签/形态切换。

- 改名交互：行内单行输入弹层，复用现有 popup 机制。

## 色环命中修复 v4（2026-10-11 14:22，wt-2）

用户实测「圆环的颜色点击选取有问题，移动不了」。根因：**坐标系混用**——`CUi::DoPickerLogic` 返回的是相对命中矩形左上角的局部坐标（内部 clamp 到 [0,w]×[0,h]，ui.cpp:1233-1236），色环分支却拿它去减弹窗绝对坐标 `WheelCenter`（约 140,120），`atan2` 恒收敛到由弹窗几何决定的固定角度 → 点击任何位置 hue 都跳到同一点、拖动看似无效。方图形态无此问题是因为它做了 `PickerX - (SvArea.x - SvHitArea.x)` 平移。

修复（ui_popups.cpp 色环命中分支）：
- 全部改为局部坐标：`Dx = PickerX - WheelHitArea.w * 0.5f`（环与 SV 方图同心，环心即外接框中心）。
- 环带命中加外径上界 `Dist <= WheelOuter + 0.5f`（此前点击外接框四角空白会被误判为环带）。
- 环内 SV 方图判定改相对环心的对称区间 `|Dx|<=SvHalfW && |Dy|<=SvHalfH`，S/V 换算同步局部化。
- 验证：game-client 6/6 增量链接、testrunner 回归 18/18 全绿、冒烟启动日志完整无崩溃（14:21:54 启动 → 14:21:59 QmClient 分发 users=136 正常）。
