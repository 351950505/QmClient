# 音频包编辑器重构

状态：已实现，待编译、测试和游戏内验收。

音频包编辑器按用途分类，每组音效只占一行。名称使用当前界面语言，同时保留英文 ID、变体数量和原文件名。搜索匹配名称、用途、类别、英文 ID 以及组内任一变体文件名。

宽屏采用左侧音效目录、右侧工作区。窄屏或放大 UI 后改为上下排列。工作区依次展示场景说明、变体选择、候选文件和文件操作。变体按钮换行排列；候选项突出文件名，完整路径通过悬停提示展示。工作区和候选列表复用现有滚轮归属仲裁，候选列表具有更高优先级。

替换针对当前选中的一个变体。保留候选试听、手动源文件试听、写入音频包和重载能力。手动源文件优先于候选文件，界面明确提示这个优先级。找不到匹配音效时隐藏文件操作；没有候选文件时仍可输入手动源文件。

写入文件时正确拼接父目录分隔符，避免创建音频包目录时误把 `audio/包名` 拼成 `audio包名`。

## 用途说明的依据

- 目录来自 `datasrc/content.py` 中实际注册的 41 组音效，不把目录里未注册的额外文件当成可替换槽位。
- 武器、冻结开火、死亡及武器传送依据 `src/game/server/entities/character.cpp`；拾取及解除武器依据 `src/game/server/entities/pickup.cpp`。
- 起跳及钩子依据 `src/game/client/gameclient.cpp`；二段跳与急停依据 `src/game/client/components/effects.cpp` 及 `players.cpp`。
- 聊天及投票提示依据 `chat.cpp`、`voting.cpp`；菜单音乐依据 `menus.cpp`；夺旗事件依据 `sixup_translate_game.cpp`。
- 左右脚文件属于地面起跳组，不是行走脚步声。落地资源单独注册，但本仓库 DDNet 服务端未发现直接触发点。
- 冻结爱心、解除武器与其他玩法下的生命、护甲含义分开说明。未找到直接触发点的已注册声音标记为取决于服务端，不推测具体跑图用途。

Gemini 参与了布局评审与文案草稿。采用两栏、用途优先、紧凑变体按钮、文件名优先和明确的单变体替换；最终场景说明及代码取舍由本任务按仓库实现核对。
