## 迁移约束

- SDL3 使用官方 3.4.18 源码，固定下载地址和 SHA-256；各平台和 Android Java 使用同一份源码。
- 保持已有配置键位编号、窗口模式、IME 候选栏行为、声音和语音功能。使用显式映射处理 SDL3 变动的扫描码。
- 重审 SDL3 的返回值、对象所有权、主线程约束及音频流生命周期，不能只替换 API 名称。
- Android 录音权限按异步结果处理，不能把请求成功当作授权成功。
- 语音保持现有 Opus 编码和 RV01 数据包。只有实际协议或服务依赖变化才部署中转服务器。
- Gemini 已进行只读方案讨论；其建议按官方头文件和真实调用路径核实后采纳。

## 已确认的整合问题

- 屏蔽词加载实现引用了不提供 `Localizable` 的头文件，导致多平台 CI 编译失败；改为引用现有共享本地化入口。
- 聊天合并合同测试依赖旧源码字符串，无法表达高亮消息不合并的行为；将高亮条件纳入生产判定接口，通过真实接口回归测试替换该项合同。
- TClient 审查分支存在 clang-format 22 格式检查失败，按 CI 工具版本修复相关文件。
- 头衔显示卡移至外观页后，赞助支持卡默认序号仍为 1；补齐当前默认顺序，同时更新旧页面迁移测试，验证显示卡实际进入名牌设置。
