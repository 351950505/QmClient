# 回放相机路径

状态：行为已确认，代码已实现，运行与视觉验收待补。

## 使用行为

普通本地 demo 播放器新增“相机路径”入口。在线回放不显示此入口。

- “编辑镜头”暂停回放并切换到自由相机。关闭菜单后移动相机和调整缩放，再打开播放器添加关键帧。
- 关键帧记录当前 demo 时间、相机中心和缩放。第一帧同时记录取景宽高比，并默认启用这份路径。
- 上一项、下一项选择关键帧；“定位关键帧”跳到对应时间并恢复保存的构图。“更新关键帧”修改所选帧的构图，时间保持不变。
- 在时间线上的其他时间添加关键帧即可调整移动时长。在相同时间添加会更新已有帧，不创建重复帧。
- 每帧可选择向下一帧平滑移动、匀速直线移动或保持到下一帧。平滑使用分段缓入缓出，空间路线由关键帧中心连线组成。
- “预览路径”从第一帧开始播放。“停止预览”回到暂停的自由相机编辑。编辑期间暂时让出相机控制，重新启用或预览时恢复路径控制。
- 第一帧之前和最后一帧之后保持端点构图。暂停、变速和进度跳转均按 demo 的绝对时间重新取样。
- 关闭“启用相机路径”恢复普通相机行为，保留关键帧；关闭路径面板隐藏辅助线。路径面板和回放显示面板互斥展开。

辅助线显示关键帧之间的路线及各帧取景框，选中帧高亮。视频导出隐藏这些辅助线，使用与预览相同的相机取样实现。

“回放显示”中的按键、强弱钩、钩索强度范围改为普通文字按钮，选中项高亮。HUD 与聊天的开关和配置绑定保持不变。

## 保存和导出

镜头文件保存在对应 demo 旁边，命名为 `<demo 文件名>.qm-camera.json`。每次编辑自动保存，重新打开同一份 demo 或导出视频时自动加载。写入失败显示提示并保留未保存状态，可点击“保存”重试；视频导出前存在未保存修改时必须先保存成功。

文件使用版本 1 的独立 JSON，不改动 demo 内容。记录启用状态、取景宽高比、按时间排序的关键帧，以及裁剪曲线所需的参数区间。取景宽高比通过已有游戏视野入口恢复，退出回放后恢复玩家的宽高比设置。

裁剪导出随 demo 另存镜头文件，按现有 demo 编辑器的 tick 偏移拼接。裁剪边界保持原来的曲线参数区间，保留片段内部运镜速度；不跨过被删除的画面继续插值。镜头文件保存失败时提示已保存 demo，但不自动开始视频导出。

## 实现分工

- `components/qmclient/demo_camera_path.h`：关键帧、绝对时间取样及裁剪重映射。
- `components/qmclient/demo_camera_file.h`：独立文件编解码、存储根定位和完整写入后的替换保存。
- `components/qmclient/demo_camera.*`：播放会话、编辑动作、保存恢复和辅助线。
- `QmUi/QmDemoCameraPanel.cpp`：播放器内的路径编辑面板。
- 原相机与播放器只接入视图取样、面板入口和导出流程。
